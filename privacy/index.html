Política de Privacidade

Última atualização: 31 de agosto de 2026

1. Sobre o aplicativo

A Calculadora Steel Framing é uma ferramenta destinada a auxiliar profissionais e usuários no planejamento e nos cálculos relacionados a projetos de Steel Framing.

2. Coleta de dados

A Calculadora Steel Framing não coleta, solicita ou armazena dados pessoais dos usuários.

O aplicativo não exige cadastro ou criação de conta para sua utilização.

3. Dados inseridos pelo usuário

As informações inseridas pelo usuário para realização dos cálculos são utilizadas exclusivamente para o funcionamento das funcionalidades do aplicativo.

O aplicativo não utiliza essas informações para identificar pessoalmente o usuário.

4. Compartilhamento de dados

Como o aplicativo não coleta dados pessoais, não há compartilhamento ou venda de dados pessoais de usuários a terceiros.

5. Publicidade

O aplicativo não utiliza dados pessoais dos usuários para direcionamento de publicidade.

6. Segurança

Embora o aplicativo não colete dados pessoais, são adotadas medidas razoáveis para manter o aplicativo e seus recursos em funcionamento de forma segura.

7. Alterações nesta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada caso ocorram alterações nas funcionalidades do aplicativo ou na forma como os dados são tratados.

A versão atualizada será disponibilizada nesta mesma página.

8. Contato

Para dúvidas relacionadas a esta Política de Privacidade ou ao tratamento de dados pelo aplicativo, o usuário poderá entrar em contato com o desenvolvedor por meio dos canais de contato disponibilizados na página do aplicativo.
